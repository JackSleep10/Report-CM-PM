📋 2. ตารางสรุปรายละเอียดและการปฏิบัติสำหรับแต่ละช่อง (Field Reference Guide)
ลำดับ ชื่อช่องในระบบ ประเภทการกรอก คำแนะนำและวิธีการใช้งาน
❶ วันที่แจ้งซ่อม
Inform Date		 ค่าเริ่มต้นอัตโนมัติ ระบบจะตั้งเป็น วันที่ปัจจุบัน ให้อัตโนมัติ ผู้แจ้งไม่ต้องแก้ไข เว้นแต่กรณีแจ้งย้อนหลัง
❷ เวลา
Time		 ค่าเริ่มต้นอัตโนมัติ ระบบจะตั้งเป็น เวลาปัจจุบัน ให้อัตโนมัติ
❸ ชื่ออุปกรณ์
Equipment Name		 🔒 ระบบเติมให้อัตโนมัติ ไม่ต้องพิมพ์เอง (Read-only): ช่องนี้จะเป็นสีเทา ล็อกไม่ให้พิมพ์ โดยระบบจะดึงชื่อ/คำอธิบายของอุปกรณ์จากฐานข้อมูลมาแสดงให้อัตโนมัติทันทีที่เลือกรหัสอุปกรณ์ในช่อง ❹
❹ รหัสอุปกรณ์ *
Equipment Code (GSE No.)		 🔴 จำเป็นต้องกรอก/เลือก ช่องสำคัญที่สุด:
  • ให้เริ่มพิมพ์รหัสอุปกรณ์ เช่น TLM-TT หรือเลขทะเบียนรถ
  • จะมี Dropdown แสดงรายการอุปกรณ์ที่ตรงกัน ให้ คลิกเลือก รายการที่ต้องการ
  • ระบบเตือน Inactive: หากอุปกรณ์อยู่ในสถานะ Inactive ระบบจะขึ้นแถบแดงเตือนและไม่อนุญาตให้เปิดแจ้งซ่อม
❺ ชม. / กม.
Hr. / Km.		 กรอกเพิ่มเติม (ถ้ามี) ระบุเลขชั่วโมงการทำงาน (Hour Meter) หรือเลขกิโลเมตรบนหน้าปัดรถขณะที่พบปัญหา เพื่อช่วยให้ช่างประเมินรอบบำรุงรักษาได้แม่นยำ
❻ วันที่ต้องการใช้
Due Date		 กรอกเพิ่มเติม (ถ้ามี) กำหนดวันที่ฝ่ายผู้แจ้งต้องการให้นำอุปกรณ์กลับมาใช้งาน เพื่อให้แผนกซ่อมบำรุงจัดลำดับความเร่งด่วนของงาน
❼ อาการเสีย *
Damage Appearance		 🔴 จำเป็นต้องกรอก ระบุให้ชัดเจนและละเอียดที่สุด: เช่น ชิ้นส่วนใดชำรุด, มีเสียงดังผิดปกติอย่างไร, รั่วซึมที่จุดไหน เพื่อให้ช่างเตรียมเครื่องมือและอะไหล่เข้าซ่อมได้ทันที
❽ ผู้แจ้ง / รหัสพนักงาน
Requester / Employee ID		 🔒 ดึงจากบัญชี Login ระบบจะนำชื่อ-นามสกุล และรหัสพนักงานของผู้ที่ล็อกอินเข้าใช้งานมาใส่ให้โดยอัตโนมัติ ไม่ต้องกรอกเอง
❾ ชื่อผู้รับรอง / เบอร์โทร
Approver Name & Tel		 กรอกเพิ่มเติม ระบุชื่อหัวหน้ากะ/หัวหน้างานฝ่ายผู้แจ้ง พร้อมเบอร์โทรศัพท์ติดต่อที่สะดวก เพื่อให้ช่างติดต่อประสานงานหน้างานได้รวดเร็ว
💡

คำแนะนำสำคัญเมื่อกด "บันทึกใบแจ้งซ่อม":

1. เมื่อกดบันทึกแล้ว ระบบจะส่งการแจ้งเตือนพร้อมสรุปข้อมูลไปยังกลุ่ม LINE แจ้งซ่อมบำรุง GSE โดยอัตโนมัติทันที
2. ผู้แจ้งสามารถติดตามสถานะการซ่อมบำรุงได้จากแท็บ "สถานะอุปกรณ์ GSE" โดยจะเห็นกำหนดวันเสร็จ (RTS Date) ที่ช่างประเมินไว้
3. เมื่อรถซ่อมเสร็จและผ่านการอนุมัติแล้ว เพื่อนร่วมงานคนใดก็ได้ที่ไปรับรถแทน สามารถเข้ามากดปุ่มจับมือ 🤝 เพื่อลงนามรับมอบอุปกรณ์ได้ทันที

แผนกซ่อมบำรุงอุปกรณ์ภาคพื้น (Ground Support Equipment - GSE) • บริษัท ไทย ไลออน เมนทารี แอร์ไลน์ จำกัด
